# Zuhri Formalism Core (ZF-Core)

Repositori resmi untuk arsip parameter fisik, arsitektur dasar, dan glosarium dari kerangka kerja Abah Muhammad Zuhri. Aplikasi ini menjembatani hukum universal (*makrokosmos*) dengan kesadaran batin manusia (*mikrokosmos*) ke dalam sistem komputasi digital.

## 📐 Rumus Indeks Keselarasan (I_ZF)
Aplikasi ini menggunakan formula inti untuk mengukur tingkat keselarasan:

$$I_{ZF} = \frac{D \cdot L \cdot \Psi}{W \cdot A \cdot M}$$

Di mana:
* **D (Data):** Informasi empiris dan data terukur.
* **L (Logika):** Struktur berpikir formal.
* **$\Psi$ (Intuisi):** Kesadaran batin atau *wening*.
* **W (Dunia):** Amal atau kerja nyata di dunia.
* **A (Akhirat):** Orientasi transendental.
* **M (Manfaat):** Dampak sosial bagi sesama (*Manunggaling Kawulo-Kawulo*).

## 🚀 Cara Menggunakan Aplikasi
1. **Melihat Kode Sumber:** Anda dapat menelusuri folder `lib/` untuk melihat implementasi logika inti (`zf_core.dart`) dan antarmuka pengguna (`main.dart`).
2. **Menjalankan Kalkulator:** Masukkan nilai parameter pada kolom yang tersedia di aplikasi, lalu tekan tombol **"Hitung Indeks I_ZF"** untuk melihat hasil perhitungan keselarasan secara instan.
3. **Otomasi & Build:** Sistem otomatisasi GitHub Actions di dalam folder `.github/workflows/` akan menguji serta merakit kode secara berkala.
